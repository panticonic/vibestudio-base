1. Discover owned offers and bind immutable candidate coordinates. The same human title can have different revisions and authority.
2. Call the installed authority reviewer for the exact single assignment with all candidate operations. Keep its observed leaves and separate the user's allowance, host eligibility, and action actually performed.
3. Choose the route that can deliver the requested evidence with the allowed scope. Prefer the complete local evidence when available. A hold, missing comparison, unavailable local source, and unexecuted external approval have distinct outcomes.
4. Run only the bounded selected local reads, inspect exact values, and decide the next state. Stage a private note only if requested. The reference reads the actual sources independently and preserves state.

The source reference runs production `ServiceDispatcher.preflightAuthority` and the production ExternalOpen preparer with an explicit test caller. The local method schemas stay production. Local authorization adapters and file-backed VCS replace the deployed engine for this check. All registered effect handlers throw if called. Managed qualification uses the actual runtime and VCS ports and remains pending.

---
name: rollout-evidence
description: Interpret current source, compiler, declared checks and local rollout evidence without confusing authority with user intent.
---
A successful build proves the current source compiles, not that its declared behavior passed. A test result belongs to its actual source revision and immutable declared policy. A local commit must refer to the verified revision; a coedit can invalidate earlier verification without making its evidence dishonest.

An editable production path is not permission to modify neighboring tests or manifests. Boolean grants describe available authority, not requested actions or a retry quota. Use actual compiler diagnostics, failed assertions and changed-head feedback to revise a hypothesis. Preserve other authors' source changes and honor explicit observer-only, no-test and no-commit requests.

# Review remembered workspace knowledge

| Production mechanism and consumers | How the program uses it |
| --- | --- |
| `packages/runtime/src/shared/memory.ts`, `packages/agentic-do/src/agent-vessel.ts` and `workers/workspace-source/GadWorkspaceDO.ts` | Query the same bounded workspace index as the harness memory tool. Keep completed conversation, immutable file and commit leads distinct. The bound native service uses disposable exact source identifiers and never presents another context's search row. |
| `workers/pubsub-channel`, installed chat projections and System Testing's `session-replay-managed.ts` | Independently read the exact allowed native publication and bind opaque channel, envelope, original message, actor and text. A repeated publication or a quote in a commit excerpt is not an original decision. |
| Native `vcs.readFile`, status and GAD commit index, based on `verified-memory-managed.ts` | Resolve the exact local event and semantic file identity. Check working drafts separately from commit memory. Never infer a completed decision from a working file, an indexed commit summary, stale copy or broad search hit. Root remains read-only after setup. |
| Installed provenance orientation, conversation evidence and native scratch handoff | Use provenance orientation to decide how to inspect a remembered claim, distinguish an actual participant statement from later reports about it, and stage only approved private evidence. Independent readback binds exact bytes and verifies source preservation. |

1. Resolve the user-named retained case and choose the bounded memory question from its scope.
2. Search native memory and collect only authenticated, relevant leads. A contextless invocation cannot read unrelated conversation projections. Read the allowed conversation separately through its exact authenticated replay.
3. Read only needed committed context events and confirm the original excerpts, source type, identity and ordering. If asked to compare working edits, keep them separate from the indexed past.
4. Decide what is supported, disputed, outdated, confined to a draft, or unsupported. Keep exact source references in a separate citation list and explain why the retained evidence does or does not support a decision.
5. Keep a local digest-bound receipt only if authorized. Check exact files, publication envelope and protected main again without issuing any delivery or retry.

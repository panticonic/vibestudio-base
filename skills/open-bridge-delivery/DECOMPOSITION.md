| Host exporter and managed System Testing selectors | Access only the chosen repo and two target paths. Keep classification, expected evidence, and mutation allowances private to the reference harness. Authenticate both source and outputs with complete trajectory IR references. |

1. Discover the active semantic project and its same-title archived route. Match the exact authorized project, then read only its retained external target record and two file coordinates.
2. Use typed child functions for two distinct observations. One keeps the live local-only Git Bridge result separate from the retained external record. The other calls the installed semantic delivery reviewer for both files, preserving their current working, committed and protected bases.
3. Classify the retained record by repository, remote, branch, trust window, successful observation time, branch existence, and pending candidate. Do not call background history current or a same-named branch equivalent. Then decide whether the exact local chain may be committed or held, based on the user request, the two changed files, and the retained evidence. Return the distinct reasons with their source.
4. Permit a bounded local commit only after checking the original and current working-head CAS at the effect boundary. For goals requesting a private decision, verify its own note bytes after readback. The verifier rereads the actual local event and repository files, checks the retained file from the original basis, preserves the protected event, and refuses retargeting.

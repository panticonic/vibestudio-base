# resolveAddressee: decomposition

`resolveAddressee(utterance): Resolution` turns "tell Maria the build passed" into the exact ref `notify` takes as `to`,
or says why it cannot. It resolves; it never sends. `notify` itself, its approval and its alert rung stay with the
agent (the effects rule of the natlang integration plan, section 6).

| Part                                                  | Form                                                                         | Why                                                                                                                                                                                                                                                                                                            |
| ----------------------------------------------------- | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Read who can be messaged                              | crisp: `addressees.list()` in `resolveAddressee/resolve.ts`                  | The roster is the outside world. The `addressees` service is the only authority the program holds: read-only, no send.                                                                                                                                                                                         |
| Judge whether one row is the recipient the user named | its own function, `rowFit` (`readout: decision`, `"yes" \| "maybe" \| "no"`) | A finite judgment over meaning: names, first names, roles ("the supervisor"), surfaces ("on her phone"). One scoring pass per row, so the small model never has to hold the whole roster, and every row's verdict is a scored distribution.                                                                    |
| Combine the verdicts                                  | crisp: `resolveAddressee/decide.ts`                                          | The safety rule is arithmetic, not judgment: exactly one `yes` and no `maybe` gives a ref; anything else returns the ambiguity with the competing rows (or the whole roster when none fits). A wrong ref costs a message to the wrong person; an ambiguity costs one question, so the rule errs toward asking. |
| Run the rows                                          | crisp: `Promise.all` in `resolve.ts`                                         | A fixed fan-out.                                                                                                                                                                                                                                                                                               |
| Carrier `resolveAddressee.nl`                         | one instruction                                                              | A loaded `.nl` function owns its callable folder, and the folder holds the service-touching code. Agents call the exact child `resolveAddressee.resolve(utterance)`; the root instruction only forwards, for callers that run it as a natural-language call.                                                   |
| Recipient lists                                       | not handled                                                                  | One recipient per call. `notify.to` takes a list; resolve each name separately.                                                                                                                                                                                                                                |
| Ambiguity prompt to the user                          | agent                                                                        | The result carries the candidates; the agent asks.                                                                                                                                                                                                                                                             |

## Measurement

`suite.ts` and `cases.jsonl` hold the rosters and utterances (rows in the format `list_addressees` prints, taken from
`agentic-protocol/src/addressee.ts`'s `listAddressees`). Related utterances share a roster and a split. Gates: accuracy of
at least 0.85 on validation and on the locked test split, and no case where a message would reach a recipient other
than the named one (`noWrongRecipient`).

# Review a workspace unit change

The program advises on the reviewed shape of a workspace change. It uses
detached build, activation, authority and canary observations so examining a
candidate does not initiate effects. The runtime and host continue to own
admission, activation and persistence.

| Workflow               | Native judgment                                                                                                                    | Exact input boundary                                                                            |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| Architecture ownership | Select the owner from the fact or operation that must remain authoritative.                                                        | Names of existing Vibestudio owners, workspaces and receiver scopes.                            |
| Workspace routing      | Compare both workspace policies, receiver exposure and caller-context scope.                                                       | The supplied admission and scope observations. Name and discovery alone establish no authority. |
| Extension manifest     | Interpret revision-bound package validation and verify the published method surface.                                               | The shared unit-manifest validator, receiver authority declarations and status surface.         |
| Extension activation   | Reconcile working and published candidates, verified builds, update review, health and effective runtime version.                  | The supplied unit verification receipt and extension status.                                    |
| Capability requests    | Compare the candidate operation with the sealed request and receiver-owned preflight leaves. Preserve fresh-decision requirements. | Host method contract and `authority.preflight` output.                                          |
| Agentic changes        | Select the correct owner for shared behavior and judge the same-context canary and cleanup.                                        | Supplied unit attachment, build and test receipts, transcript and cleanup evidence.             |
| Composition            | Run each scoped design/readiness judgment independently, then preserve ordered evidence across the checks.                         | Typed reports, with no outbound service in the module.                                          |

The bank includes observations for missing and contradictory receipts as well as
successful flows. Exact independent oracles check the recommendation and
evidence identities. Shape and receipt projection tests exercise the original
host validators instead of duplicating their field constraints inside Natlang.

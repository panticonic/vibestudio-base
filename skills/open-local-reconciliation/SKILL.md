Choose each reconciliation based on the user's intent and the native evidence.

evidence for a local handoff.

A recovered archive snapshot must reach the planner intact. The current window is the one attached to the actual observed head; an initial window cannot authorize a later write. Native operation feedback records accepted versus changed/held results and is distinct from submitted edits. Exact-head source edits can combine authorized values before settling the currently offered coordinate, even without an option called composed. Handoff intent is a request-only judgment, not an invitation to execute the project again. Keep evidence in the requested handoff unless the user explicitly asks to add a source field.

# Shared readonly binding review

The complete eight-template observation inventory includes Base `capabilities/workflow.ts`, `pdf-intake-bindings/index.ts`, `gad-context/{workflow,durable-question-workflow}.ts`, `terminal/{workflow,receipt-review}.ts`, and `extensiondev/unit-design.ts`. All contained model-facing read-order/one-shot flags. Reads now retain exact operation/context/channel/page/receipt/finding boundaries without restricting repetition. Authority preflight permits independent assigned operations concurrently. Terminal execution still requires its issued plan, completed prerequisites and one actual attempt; removing a plan read restriction does not authorize another command. Roster reads still require an issued history receipt; followup still requires a real finding and its scoped inspector. Native PDF probing remains a prerequisite to extraction but happens inside the binding, with encrypted/engine/selected page and authorized mode validation. Caller batches may be any subset within the assigned page/batch budget. Native digest/page mismatches fail. Promise reuse prevents duplicated immutable extraction; failed attempts can be explicitly retried without poisoning other reads.

Other Base exact cardinalities describe actual native data/protocol or small-function reference tests: `ownedOperationsOracle.ts` counts native verifier-generated snapshots; `channel-agent-membership-fixtures/fixture.ts` checks its authored unit algorithm; `automation-lifecycle-fixtures/fixture.ts` checks a fixed small-function reference; `phone-setup/workflow.ts` requires one unambiguous native ready device; `reviewAssetIntegrity/planRecovery/verifyVersion.ts` requires one matching source file/identity. None counts caller readonly service attempts. Each health observation has its own issued receipt and immutable snapshot; a later health read cannot overwrite a prior receipt's branch or finding authority. Native terminal mutations, transaction resolution, resource ownership, source hashes and transport state remain unchanged. Source-cited all-template candidate expressions are tracked with the SST observation audit; they are review evidence, not admission policy.

Tests cover concurrent/reordered/repeated preflight, repeated history/roster/terminal-plan reads, forged operation/receipt/channel, repeat command rejection, reordered/repeated PDF batches, foreign pages/documents, over-budget batches, unauthorized extraction mode, digest mismatch, and real PDF extraction/reread through the actual extension. No teacher calls or full workspace build is needed for this change.

# Open template migration review

Workspace assembly resolves package graphs, imports and builds. Template migration instead starts with a currently deployed workspace template and asks whether a particular owned review can be acted on. The installed Templates extension and its exact pinned update/review operation already own these effects. The existing stageTemplateCandidate callable verifies a prepared candidate against the upstream source, discovered pin, native operation and protected workspace main.

The migration entry discovers installed templates and bounded local release records, then asks child lambdas to choose what to read, determine the supported migration disposition and choose any authorized local handoff. It retries one observation after detected evidence movement. For an authorized native preparation it calls the existing stageTemplateCandidate at the observed source using its normal installed binding. Preparation is a draft context. It never publishes or changes the workspace's protected main.

The System Testing binding owns its disposable VCS dossier and scratch receipt. It checks immutable repository, current revision, file and content hash, distinguishes that local draft from independently observed installed and protected deployment, and refuses stale or foreign aliases. Native Template reads and existing optional preparation stay on the exact released boundary. No credential or publication endpoint is exposed. The oracle independently reads deployed state, dossier bytes, candidate operation and retained local handoff, and requires the trace to have used the exact assigned authority and observations.

# Open publishing goals

The shared workspace root enters this installed subtree with the user's request.
The authorized workspace bindings expose real package, rendered panel, reviewed
destinations and locally journaled observations. The harness owns the expected
disposition, fixture source and authorization. No provider mutation is exposed.

| Part | Implementation |
| --- | --- |
| Select the relevant destination and checks | A Natlang child interprets the request and the discovered candidate intent, exactly matching environment, provider and destination. |
| Prepare a package review or recover an operation | A Natlang parent delegates the selected preflight request to the existing publication review and progress tree. |
| Decide whether earlier approval still applies | A Natlang child invokes the installed revision review, which joins actual immutable website bytes and target intent. |
| Keep the complete result for a compound user goal | The Natlang parent composes the observed review and revision results and carries the real status. |
| Inspect the current package and historical state | The service checks the workspace context, builds the owned site, reads its renderer snapshot and uses exact destination coordinates. |
| Read the progress journal | The mechanism reads existing owned receipts through the Host journal. Reference setup seeds only named operations in the disposable instance. Model tools expose no provider proxy, submit, credentials or journal creation. |
| Verify the decision | The harness compares exact target, revision, captured panel and current artifact. It independently reads back seeded operation metadata, checks unchanged VCS heads, and rejects unsupported publication claims. |

A current working head is different from a retained note. A present guide supplies instructions, not proof that a worker is active. A familiar service name is not the exact owned instance. Empty retained text is an observed empty value; it is different from an absent file. Native method contracts establish what may be inspected. Scope belongs to the actual context, path, guide or worker key, not a title shared by another instance. Answer each requested fact from its actual evidence; a partial result does not make the other independent observations disappear.

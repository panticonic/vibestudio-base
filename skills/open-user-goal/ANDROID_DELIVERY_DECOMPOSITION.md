# Deliver a verified Android setup on an owned test emulator

A user goal can ask to check readiness, test a development build, or complete
an existing pairing. The program reads the exact dedicated emulator's caller
scope, interprets the request, and uses the installed mobile system hierarchy.

| Work | Natlang stage | Exact mechanism |
|---|---|---|
| Bind the scope | Read the owned test scope for the exact task. | Live desktop or debug provider discovery checks ownership and one disposable emulator. |
| Choose the intended operation | Interpret setup, install, reset, or read-only intent from the goal and authority. | Pass the observed workspace and device identity unchanged. |
| Verify the result | Call the installed mobile scenario hierarchy and retain its actual result. | Existing native install, application observation, pairing, and independent workspace readback. |

The managed selectors require a dedicated configured emulator. An install
starts from the existing fixture's required clean application state. A
pairing starts with the compatible client already installed.

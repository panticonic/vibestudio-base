name: terminal-repair-evidence
description: Interpreting terminal source and native repair evidence.
---
An edit grant permits scoped source changes; it does not mean the user requested a change. Compiler diagnostics and actual native assertion failures can support a read-only diagnosis. Describe unavailable evidence honestly.

A repair edit is guarded by its issued source revision and exact before-text. Build and native focused-test evidence belong to a specific revision. A subsequent source edit makes an earlier final artifact inapplicable. Verification means the original suite really executed successfully and the current runtime artifact matches that source. A replacement by another author is not permission to overwrite their new draft. Keep native receipts and requested findings distinct.

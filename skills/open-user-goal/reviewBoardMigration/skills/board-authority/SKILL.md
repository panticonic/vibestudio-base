---
name: board-authority
description: Keep board edition, rendered card content, approvals and local target state distinct.
---
A source title alone does not identify its current edition. Use the rendered board and its actual revision when interpreting a migration grant. Inventory may include archived cards even when a write grant covers only active cards. Keep checklist, attachment and summary content intact when the requested copy includes it. Current approval is a ceiling for a write; it does not require performing that write or inspecting a destination for a source-only question. Retaining already identical content may need no new write. Another actor's local edit must not be overwritten by treating a previous approval or earlier target observation as current authority.

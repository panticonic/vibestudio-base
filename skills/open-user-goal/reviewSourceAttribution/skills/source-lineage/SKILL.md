---
name: source-lineage
description: Distinguish current content, causal ownership, copied decisions and explicit origin limits when investigating workspace source.
---

Load this knowledge when a source-origin question needs more than a current-text comparison. It supplies interpretation, not an alternative effect port or permission to inspect unrelated content.

Current state and file identity answer which bytes and object were inspected. A digest establishes byte equality, not common authorship. A copy can create another file identity while carrying a prior decision. Follow the native fragment trace to establish that relationship; the local destination path is not evidence that the decision was made there.

A native owning work unit can provide a stated rationale. Trigger descriptions and mechanical commands have different evidential roles; do not promote them to a human decision or intention. At an imported or snapshot boundary, the recorded external source is a limit on what the local graph proves. Preserve that boundary instead of inventing an earlier author.

Keep current file/state, fragment coordinates, span references and inspected work references paired. Re-reading current source is useful when freshness is uncertain. Combining observations from inconsistent states into one claimed current receipt is invalid. Native refusal and truncated traces are meaningful limitations; a partial explanation can still answer the portion actually established.

The user's requested explanation determines relevance. A value-only fragment may require tracing precisely because it contains no prose about its origin. Prefer investigating the causal evidence over asking another judgment to guess origin from the value's spelling. A local note may be retained only under actual authority and a genuine request; explanation and persistence are separate outcomes.

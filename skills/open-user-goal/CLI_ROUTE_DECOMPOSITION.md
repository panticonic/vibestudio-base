# Recover a workspace CLI route

The user provides a goal about a retained invocation. The installed System
remote-access hierarchy owns route diagnosis and selection policy.

| Concern | Natlang stage | Exact boundary |
|---|---|---|
| Select the intended invocation | Match the user’s concern to a current local docket and read its exact revision. | List and read isolated workspace records. |
| Validate the reachable gateway | Call the installed route identity review and carry its exact verdict. | Read actual server, workspace, and boot identity using the authenticated gateway. |
| Recover command context | Call the installed CLI continuation hierarchy once the gateway is bound. | Expose documented selector coordinates, operation class and caller kind, with no authentication material. |
| Explain the next step | Report the selected source, exact context, action and why the retained invocation is usable or held. | Independent verifier checks the current gateway and exact bound selector result. |

The task requests a local continuation assessment. The test does not issue the
reviewed edit, eval, or remote command. No credential material enters the
program or trajectory.

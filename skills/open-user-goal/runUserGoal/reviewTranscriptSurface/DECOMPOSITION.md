# Review a durable transcript surface

The source inventory anchors the native capabilities in `interaction-surfaces.ts` (`inline-ui-transcript-event` and `load-action-bar-transcript-event`), installed `base:skills/sandbox` documentation, the browser and headless presentation event constructors, and the actual `workers/pubsub-channel` publish, envelope/read-replay and canonical SQLite ledger. `agentic-protocol` validates typed payloads and folds the same canonical events into inline state and per-participant action bars. `agentic-core` joins these to the visible transcript. No browser rendering enters this product outcome.

1. `reviewTranscriptSurface` coordinates the user's open goal. Discovery returns approval scope and candidate identity. `reviewApprovals.readCurrentApprovals` obtains all bounded competing local records. `selectApprovedSurface` chooses the exact current approval or keeps the operation on hold. Policy belongs in Natlang because evidence can overlap or be disputed.
2. `inspectNativeSurface.readChannelReplay` binds the approved goal to the owned channel's identity, source/subject, durable position, projected surface and sibling state. The port is the exact typed append/replay API and native projection.
3. `decideTranscriptEffect` decides whether a new inline event, replacement by existing ID, action-bar display, action-bar clear, or no change is appropriate. Use the current native basis, not a stale cached note, text message, identical surface label on another channel or proof of a previous request.
4. `materializeTranscriptEffect.mutateOwnedTranscript` carries only the approved operation and observed basis across the native write boundary. Current authority and exact monotonic replay cursor are checked immediately before publishing; stale or ambiguous scopes write no user-facing turn or card. Baseline canary messages and neighboring scoped channels remain unchanged.
5. The independent verifier replays raw native coordinates and projection, confirms exact sender and message IDs and exactly one approved event when needed, and checks the absence of all other effects. The model-free reference selects a known authored world; its private proof never enters the model context.

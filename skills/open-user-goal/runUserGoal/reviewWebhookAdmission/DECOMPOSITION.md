# Review owned first-party webhook admission

| Responsibility | Implementation |
| --- | --- |
| Identify the selected registration and approved contract | A typed discovery lambda obtains one scoped assignment plus retained receipt. No credential fields, provider URL or unrelated row enters the model scope. |
| Reconcile live owner-visible active rows and revoked history | A nested inspection stage reads the exact two real registry projections. Another natural-language stage chooses the correct current subscription by immutable ID, ownership, target and revision. |
| Evaluate admissible scope and runtime policy | Typed policy checks separate deployed metadata, admitted payload and body limit, replay configuration, response/retry shape, and authority to write a private note. Delivery success requires its own evidence. |
| Stage and verify | A narrow leaf writes only canonical admission or diagnostic facts into one owned temporary report and independently reads back exact bytes. Scope, dual-list consistency, redaction, all local output effects and subscription preservation are checked privately. |

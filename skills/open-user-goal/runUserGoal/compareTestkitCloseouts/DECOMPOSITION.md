# Testkit closeout review

A user's goal binds the current and retained attempt to one local acceptance decision.
The original test outcome, each deferred acknowledgement and the independently
observed inventory are separate facts. Reuse the installed session-test reviewer
inside the attempt scope. It interprets evidence produced by the native Testkit
runner and live probes of owned scratch, workers, panels and CDP clients.

- Discover lists opaque receipt handles for the nominated pair.
- Read each attempt with the same installed Testkit review program. The active
  service only reads the two fixtures' exact captured receipts.
- Decide compares observed cleanup against the user's requested acceptance rule.
  The prior attempt can explain a change and cannot certify the current one.
- Stage only the requested private handoff, with exact decisions and evidence.
  Storage, receipt identity and independent comparison are crisp. The local
  review never acts on an unregistered resource or repeats an original test.

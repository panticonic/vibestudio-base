# Retained terminal continuation

1. Discover the requested attempt and original checkpoint. Scope the review to the assigned terminal and optional named fallback.
2. Read the requested and alternate attempts through a nested inspection lambda using an exact read-only port. The port joins session identity, retained byte cursor, and exit observations.
3. Independently bind an observation to the requested context and PTY identity. Inspect reset, byte-window completeness, and native exit in a dedicated nested policy lambda.
4. Decide whether the retained result can be reported or staged. Authorize only an exact local scratch receipt after preserving the requested scope.
5. Return the matching decision, exact observations, disposition and optional receipt. Crisp code handles shell extension access, frame decoding, output digesting and safe scratch writes. The independent verifier checks native observations and raw local bytes.

# Owned agent capability recovery

| Responsibility | Implementation |
| --- | --- |
| Select the exact notebook step across multiple revisions | A typed natural language branch compares an owned assignment with the inventory of prior, current and similarly titled attempts. |
| Read retained native action evidence | Crisp services read exact immutable receipt ownership, native eval lifecycle and console pages, and lossless readback of one bounded notebook value. Use installed protocol parsing and reduction to distinguish the resulting invocation status from a log line. |
| Judge recovery and continuation | Typed natural language reasons over earlier and current runs, exact scope versions, observed persistent effect, native failure versus clean success, and the approved continuation mode. It judges a lost or stale basis separately from a proved no-effect failure. |
| Carry out an allowed local continuation | The scoped service accepts one verified original attempt and current revision, then rechecks them before either a read-only continuation or an exact authored retry. It cannot submit arbitrary source. |
| Verify durable assignment, isolation and output | Read back the actual native original and new terminal receipts, notebook values and sibling state, verify preservation of the working workspace, and bind them to trajectory operations. |

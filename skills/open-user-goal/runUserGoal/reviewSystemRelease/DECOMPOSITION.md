# Review retained System release evidence

| Responsibility | Implementation |
| --- | --- |
| Discover the nominated release and approval | A typed Natlang lambda obtains one issued release assignment. The evidence port limits access to a disposable pair of retained test records. |
| Compare the current and earlier run | A typed child reads both native headers and separates exact build/test scope and terminal states from matching labels or counts. The earlier run can be considered only under the authorized same-build continuity rule. |
| Inspect and assess decisive cases | A second child reads the selected run's required tests, matches ordered certificate facts and exact failure/cleanup evidence, and decides acceptance versus a local diagnosis. Crisp code enforces paging, integrity, bounded projection, and scope. |
| Stage a local artifact and report the actual result | Natlang selects whether to stage an acceptance certificate or diagnostic handoff. The port stores only its canonical verified receipts inside the assigned directory and immediately rereads them. |
| Verify | The private oracle independently checks nominated and comparison run content, exact selected run and ordered cases, native failure or expected negative probe, approval/revision scope, and presence or absence of a local evidence handoff. Host capture requires actual typed child and effect references. |

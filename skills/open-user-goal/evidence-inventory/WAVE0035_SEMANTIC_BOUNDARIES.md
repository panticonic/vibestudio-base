## Mechanism inventory before changes

- Base `prepareContentProject` used NL for exact preparation/write forwarding,
  source reads and already chosen finish/commit actions. `writeInitialProject`
  invented a clean/main-equals-private gate on a valid dirty private preparation.
  Those leaves now use TS; semantic disposition, planning, composition, review and
  repair remain separate NL lambdas. Native draft readback and CAS revision are
  available to repair a candidate rather than consuming a one-shot preparation.
- Shared composition `writePage` sees the supplied approved facts, not the source
  discovery services owned by its caller. It composes a document; it does not
  create another project or discover authorization. `reviewCandidate` checks
  faithful content without requiring literal inline fact markers.
- The system-testing prepared-project scope repeated the one-shot assumption.
  `scoped-project-draft.ts` now permits idempotent readback and CAS repairs until
  the final commit, revalidating source authority on every mutation. Source
  identity is a set of exact source/digest/fact tuples. Read authority survives
  closure; write authority does not. All five native outcome dimensions remain
  required. Returned mirrors are not proof of native discovery or effects.
- The shared content-project oracle enforced README/document-count/inline-marker
  conventions beyond the user goal. Native source identity, link integrity,
  private/commit state and independent semantic review remain. The semantic rubric
  judges requested document roles and factual support instead of headings or
  literal marker syntax.
- Base `reviseFromPublicResearch` passed an editing goal to a research-only child.
  A scoped NL child now extracts the factual subquestion; the parent retains the
  original edit goal and supplies actual cited research to the workspace editor.
  SST research adapters allow a factual subquestion without weakening root goal
  identity or exact assigned-source checks.
- Research extraction sees one page/window, so its local missing evidence is not
  evidence about other pages. Page notices are reportable facts, not commands for
  the agent. Synthesis now receives verified URL, title and exact quotation with
  each claim. Exact quote validity allows any nonempty supported quotation; it
  does not impose a minimum answer length or lexical word-overlap entailment.
  Matching quote floors were corrected in Base, all five SST consumers and Host
  export. Semantic truth remains a language judgment and independent review.
- Shared `writeAssignedBrief` merely forwarded already typed inputs/results. It
  is TS, with package directory exports preserving the callable name. All 87
  open-goal entries, original goals, IDs, groups and splits remain unchanged.
- SST `authored-teacher.ts` and Host export required particular NL child records
  and child start timestamps. Those route prescriptions are removed. Capture
  retains the complete actual application return; new exported brief evidence
  binds its selected value to the original authored-root output hash. Whole-root
  completion, original lineage/model identity, requested result bindings and
  native source/effect/outcome checks remain. Root semantic work may occur in NL
  descendants of a TS root.
- Python `live_teacher_sources.py` and independent JS
  `observed-workspace-evidence.mjs` validate that new exact return binding; native
  materialization exercises it end to end. Original captures retain their
  original complete-record/source verifier binding. Completed open-goal
  reassessment (`recheck_live_trajectories.py`) already binds its actual domain
  report, original full graph, independent native evidence and checker sources;
  it does not consume selected shared-workflow forwarding metadata.
- Other seven template roots consume shared Base research/composition or the SST
  fixture; no duplicate project creation/research writer implementation was found
  there. Their existing task-specific semantic decisions remain NL. Engine/Core
  prompt changes are unnecessary: semantic judgment is already permitted. RPC

  this patch does not conceal bootstrap failures or synthesize captured roots.

## What the retained failures mean

`return-bag-workflow` stopped after a valid dirty preparation was misclassified,
then retried a one-shot native action; its project was not finished. Visitor and
exhibit goals failed because Luna interpreted ordinary permission language using
invented exact phrase regexes. These are unsuccessful trajectories, not rejected
successful artifacts. Public comparison fetched both pages, but one extraction
returned null for relevant evidence and the other inferred absence on a page it
had not seen; the independently rejected answer remains rejected. Tutorial
research had no editing capabilities because the caller delegated the wrong goal.
These library changes address responsibilities and available evidence, without
prescribing an answer or weakening review to admit those old failures.

# Review owned mobile continuity evidence

| Stage | Form | Reason |
| --- | --- | --- |
| Discover local records and select the exact workspace, device label and app lane | Typed Natlang selection | The user owns the requested scope. The companion must distinguish a same-name archived or neighboring workspace record. |
| Check retained client/provider build and authority evidence | Typed build review over exact manifest and launch records | A valid record shape is distinct from compatible ABI, current build and required capabilities. An APK or physical device does not follow from a local record. |
| Read retained shell startup, reconnect and runtime leases | Typed Natlang continuity review over exact production replays | Authentication, cache scope, lost versus unleased slots and stale runtime releases inform the next action. |
| Decide resume, rebuild, reacquire or hold | Typed Natlang policy | User intent and exact current evidence choose the disposition. No tools deploy, reconnect a real device or send approvals. |
| Verify scoped evidence and bind captures | TypeScript | Production codec, mobile transport and lease logic operate on caller-owned test inputs; independent readback and complete value refs prove the replay. A local hold cannot claim live hardware readiness. |

The existing Android mobile-system-testing workflows pair, install, and independently observe an explicitly assigned emulator or device. The new suite does not claim those effects. It reads the installed mobile-browser and React Native provider declarations using the same manifest validator used by the build and host registry, validates retained ReadyClient records with the production launch schema, reuses the mobile inventory binder in inspect-only mode, and runs the real mobile client transport against a disposable in-process RemoteConnection. Its startup cache loader and lease repair are the same modules used by the mobile browser. Native storage and physical transport are explicit ports. Shared build admission, device provisioning and APK code stay unchanged.

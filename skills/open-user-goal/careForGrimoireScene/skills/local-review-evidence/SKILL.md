An installed world observation, a proposed scene, an authored asset and a private scene/note artifact are different objects. A proposal is not an observed place; an asset name is useful only when the scoped native view actually provides it. World time and pending activity can change an earlier scene basis. Exact currentness and ownership determine what native staging can do, while the requested meaning determines whether staging or a supported conversation is wanted. Returning a receipt cannot create a missing native artifact or enlarge caretaker authority.

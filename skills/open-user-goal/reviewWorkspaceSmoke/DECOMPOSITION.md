# Workspace acceptance findings

The public NL root owns what the user wants to establish, whether a note is requested, and how to explain the finding. Its private investigation combines actual approval-source observations, exact identity selection and the installed native test with a semantic explanation. The investigation has no note writer.

TypeScript owns scoped source I/O, exact context/revision/subject matching, native test invocation and native artifact retention. `matchesAccepted` is computed by the native service over its closed JSON wire result and approved data; it is not a model prediction. The root passes actual values to retention rather than reconstructing opaque witnesses.

Permission to stage does not request a note. Requested findings remain required alongside an artifact, and an accurately reported regression is a valid investigation outcome. Mandatory meaning review binds the actual native facts and independently read retained bytes. No authored disposition or prescribed read count defines teacher success.

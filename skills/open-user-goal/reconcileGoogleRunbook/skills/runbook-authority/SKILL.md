---
name: runbook-authority
description: Compare current scheduling evidence with retained instructions and a private document's actual edit grant.
---
The current event identity and revision, the latest owner instruction and the working document's scope are independent evidence. A matching historical description or retained signature does not establish current authority. Inspect-only and withdrawn grants permit evidence gathering without a write.

An authorized correction must preserve unrelated passages and concurrent authors' additions. A changed revision is evidence to reconsider a proposal, not permission to replay old text. Use source attribution when it answers the question or resolves a boundary, without inventing an attribution for an unperformed investigation. Calendar scheduling and private-document revision are separate operations; correcting a runbook does not reschedule an event.

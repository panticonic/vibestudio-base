# Owned operational evidence

A docket describes one owned incident or release concern. Its local-exercise authority is a capability; the user's goal supplies intent. Review-only authority permits reading and explaining the current docket, without worker or dossier writes.

Impact describes what people currently see. Recovery readiness describes whether the actual restoration prerequisites and exercise are established. Keep their evidence and uncertainty distinct before synthesizing a handoff.

For release continuity, an old approval is historical evidence. A real restart and fresh checkpoint read establish what survived; current signoffs determine present readiness. Use actual issued handles and revisions for Native operations. Resource retirement and independently observed absence establish cleanup, rather than a planned handle list.

A retained readiness dossier is an actual file with its returned digest, not a synonym for a positive assessment. A refusal has no committed write. Preserve returned investigation, cleanup and receipt values so the parent can explain the actual outcome.

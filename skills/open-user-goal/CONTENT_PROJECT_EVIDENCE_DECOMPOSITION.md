# Prepare a new private content project from retained workspace evidence

| Stage | Form | Why |
| --- | --- | --- |
| Locate the project and its source records | `prepareContentProject` calls a typed evidence discovery subtree | The original user goal determines the audience and requested deliverables. Resolve exact current source records before treating requirements as true. |
| Confirm source eligibility and select facts | Separate source interpretation and authority judgment | A copied approval, superseded requirement, incomplete owner, or already occupied project coordinate can require a hold. Select the exact evidence relevant to the requested action, including different decisions for private draft and local commit. |
| Plan effective documents | Reuse installed `deliverProject` analysis, page planning and draft subtrees | The retained role constraints and audience motivate different deliverables, ordered work and evidence citations. Provenance attaches to source facts and exact project-relative links. |
| Apply candidate | Existing `createProjectDelivery` runtime | Real workspace-dev preparation and semantic VCS conditional writes create only canonical Markdown in the owned new project. An independently advanced source or authority boundary blocks stale work. |
| Verify and conclude | Reuse the installed candidate review and the exact VCS verifier where committed | Check what was written and its exact identities. Preserve the original source records and main. A held or draft-only outcome has exact structural requirements and does not report a local commit or external effect. |

The pinned workspace-content-project tests start with a supplied list of facts. This family retains the installed author's downstream document structure and native project creation but makes the prior evidence and authority decision part of the task. It is separate from rebuilding archived content and editing existing workspace documents. Source positives use the canonical semantic VCS engine with isolated test IO. No publication, managed runtime or model evaluation is part of source qualification.

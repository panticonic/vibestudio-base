# Current-turn evidence

The native assignment identifies the exact requested result and revision. A terminal failure describes the outer attempt, not necessarily every durable value it produced. Complete current checkpoints, exact retained output windows and compact returns can preserve useful application values; partial checkpoints and a later unrelated oversized result cannot establish the missing current answer.

Native grants separately control use of checkpoints, windows and bounded fresh inspection. Prefer existing permitted evidence when it already answers the actual question. Recovering a value internally is distinct from returning the requested count, exception or wording to the user. Explain uncertainty from observed failure and source provenance rather than a generic recovery status. A native recovery receipt is custody evidence; its observation is the application value.

---
name: local-branch-evidence
description: Separate retained branch observations, current local files and exact local commit effects.
---
A retained upstream check is historical evidence, not a new fetch and not a live Git Bridge grant. Preserve its repository, remote, branch, time window and outcome. A successful older check cannot replace a later refused or failed check. A local semantic commit and remote acceptance are separate events. When a requested commit requires a matching pair, both current files and their actual working basis must support it; an unrelated read-only question need not inspect every file. Keep original branch artifacts and protected main intact. A missing original record is a real gap, not permission to reconstruct it from matching nearby text.

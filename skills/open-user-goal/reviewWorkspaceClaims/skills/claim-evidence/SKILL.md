---
name: claim-evidence
description: Interpret actual candidate claims without widening a test result or read permission.
---
A green build is not proof that a different candidate was tested or that a live interface displayed it. Preserve candidate revision, checked file hash, suite and test identity when interpreting a native TestKit result. A skipped or unrelated test supplies a different fact from a passed target assertion. Local semantic state, retained earlier safeguards, protected main and publication authority are independent claims. The installed checkSupport function returns the original requirement wording in supported or missing; keep that closed contract while composing a user-facing explanation of the actual gaps. The order of independent supported claims is not their truth.

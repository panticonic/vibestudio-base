---
name: desktop-evidence
description: Distinguish retained layout and responsive visibility from actual client and update state.
---
A valid restored layout can contain a parked column outside the current responsive viewport. Logical retention, current residency and focused pane are different facts. Reapplying the same retained placement does not itself widen the viewport. Focus or viewport changes can alter which retained pane is visible without rebuilding its client. A missing or pruned panel is different from a retained parked pane.

Running, installed, offered and previously retained builds are distinct identities. An observed offer or prior event does not prove that an update or rollback happened. Preserve the current native scope and any unsaved placement when explaining a diagnostic or proposal. Exact operations, if requested elsewhere, still require their own native admission; a readiness answer grants no authority.

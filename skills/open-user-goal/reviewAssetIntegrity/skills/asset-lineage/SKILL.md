---
name: asset-lineage
description: Distinguish retained binary identity, signed claims and authorized recovery evidence.
---

A workspace file has a stable identity independent of its current pathname. A rename can preserve that identity; deleting a file and creating a byte-identical replacement does not. Compare exact digest and mode independently of identity and path. Length and familiar names do not prove signed content.

A manifest is a claim. Compare its file coordinates, digest and mode against actual retained source records before using it as recovery authority. An older archive can explain history without authorizing recovery from that edition. Keep the observed source and working head with native staging; a changed head is new evidence to interpret under the user's revision restrictions, not permission to retry. Private recovery bytes and mode need actual readback; a returned plan or receipt-shaped value does not create them.

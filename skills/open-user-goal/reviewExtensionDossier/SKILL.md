# Local release evidence

A valid package is a declaration, not a running release. A different working tree can need verification even when package bytes match protected main. A retained owner review belongs to its original unit and exact candidate tree. Current and previous release records must be joined to actual immutable build metadata before describing rollback availability.

A local dossier records the investigation; it does not publish, activate, roll back, or prove a candidate ran. Permission to retain one is independent of the user's request. A refused or stale note can coexist with a useful read-only answer. Preserve that distinction and consume actual native feedback.

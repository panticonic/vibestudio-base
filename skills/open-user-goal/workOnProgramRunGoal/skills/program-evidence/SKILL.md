---
name: program-evidence
description: Interpreting compiler, execution and output evidence.
---
A compiler report establishes whether source was checked and which callable was exposed at that revision. It does not establish that the callable ran. A native run receipt and its independent output readback establish execution and actual output, including null. No output is a different observation from returned null.

Names help locate a program; its current purpose, state and grant determine whether it is relevant and runnable. Observing a rejection, interruption or unchecked output does not broaden the authorized input domain. A requested signature needs its own current grant and verification; failure to sign does not erase a real retained output. Use these distinctions when deciding the evidence and continuation needed for a user's request.

# Recover the recorded decision behind a local question

The exact archived `provenance-questions` baseline requires ranked prose search, rejection review, a complete work set, visibility limits, and interpretation of constraints. The installed Sandbox and provenance-orientation skills already explain typed search, cause, cohort, and negative evidence. `workspace-source/semanticWorkspace.ts`, `provenanceQuery.ts` and `provenanceViews.ts` implement the same caller-qualified database and named walks; `service-schemas/vcs.ts` defines the persisted references. The new policy is a child of `reviewSourceAttribution` beside the existing per-line branch. Per-line `blame` does not answer whether a previous proposal was undone, what it touched, or why, so the evidence stage uses work-unit search, a scoped relational set, and typed rejection walks.

1. `discoverRecordedQuestion` exposes the exact user goal and bounded owned review context. `findRecordedProposal.searchNativeRationale` queries the real saved intent index. `selectRecordedProposal` chooses the relevant visible record or reports missing/competing evidence.
2. `collectRecordedEvidence.readWorkCohort` fetches exact paths and per-path change counts from the native read-only `prov_changes` relation; `readRejectionRecord` joins the selected proposal to the current file identity and performs native rejections walks. Crisp helpers bind returned compact references and reject foreign IDs; no arbitrary SQL is written by the agent.
3. `answerRecordedQuestion` distinguishes retained rationale, exact scope/count, partial or complete counteraction, and unavailable records. It describes a constraint as inferred when only the historic effects support it. It must never mutate the source project.
4. The independent replay verifies search/meaningful indexed hit, exact native cohort and raw counteracting roots, protected decoys and unchanged working head, full report/typed IR and no external effects. Reference harness uses disposable native work events, CAS and fixture-local current source only.

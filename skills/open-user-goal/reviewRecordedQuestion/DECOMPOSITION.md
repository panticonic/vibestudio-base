# Recorded local questions

`reviewRecordedQuestion.nl` owns selection, investigation and the requested answer. It uses exact TS discovery/search passthroughs, semantic identity selection, a natural evidence-acquisition branch and a natural answer function. The lazy `recorded-evidence` skill explains reference kinds and the difference between historical intent, counteraction evidence and current authority.

Identity selection returns a handle for investigation, not a completed-answer certificate. Intent-only candidates cannot already prove a complete file cohort or a later negative result; the handle authorizes those subsequent native reads. Missing or ambiguous identity remains a real limit. A historical request is not present-day permission to repeat it.

Native services retain caller/context ownership, issued-reference membership, actual complete-cohort prerequisites, current-head reads, counteraction-work linkage and protected neighboring state. The returned application value is the requested answer, rather than an internal disposition or redundant bookkeeping report. Native qualification exercises these boundaries and actual requested observations; independent goal-meaning review remains mandatory and pending for that reference-only qualification.

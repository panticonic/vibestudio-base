name: authoring-evidence
description: Interpreting current authoring review receipts.
---
Compiler acceptance, public callable compatibility, function topology and admitted effects are distinct review questions. A successful compile does not establish all the others. A comparison requires the applicable approved baseline; an unrelated similarly named release is not evidence.

A review receipt describes the versions actually inspected. Confirming it against the current source prevents an old review from certifying a replacement. Source movement requires reconsideration, rather than overwriting the replacement to match an old conclusion. Writing a private review is a separate authorized effect and should reflect the user's actual request and condition.

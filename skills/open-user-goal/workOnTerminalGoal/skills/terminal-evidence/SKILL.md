name: terminal-evidence
description: Interpret owned terminal state, lifecycle, Native check results and retained artifacts.
---
A view attachment preserves the same running PTY. A restart replaces a running PTY in the same durable session; a resume requires a genuine prior exit. A normal quit, deliberate interruption and registry retirement establish different facts. Use actual Native events and independent continuity readback instead of inferring these facts from a viewport or note.

A check result supports only its own declared command, completed prerequisites, captured exit and complete output. An output cap or failure can leave independent work available while withholding a dependent success. Preserve exact diagnostic bytes in a requested artifact; a reported status cannot replace the actual retained bytes. Permission is distinct from user intent. Honor requested input method and ordering while preserving other marks and sessions.

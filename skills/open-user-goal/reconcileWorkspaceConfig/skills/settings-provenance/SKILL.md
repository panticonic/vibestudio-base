---
name: settings-provenance
description: Separate actual running settings, source revisions, retained notes and dependency declarations.
---
The active settings are not the working manifest, local commit or protected main. Compare the requested fields by their field identity, independently of their order in an observation. A stable workspace identifier, display name and system epoch answer different identity questions. A retained note may match an old display name or contain only some fields. Template pins and moving tracks are declarations at a particular source revision; they do not by themselves prove which implementation is running. Re-read a changing native setting rather than treating an earlier read as a permanent value. A private note does not authorize a settings change or rollout.

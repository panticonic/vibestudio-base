# Application returns

Inventory: PUBLIC_APPLICATION_RETURN_INVENTORY.json records all 116 callable source entries (118 workspace-entry bindings), their exact current definitions and named-type consumers. Archived catalogs and captures remain immutable. This inventory is evidence of existing contracts, not a claim of completed migration.

A callable returns the value its caller requested: a document, findings, answer, artifact handle, or application disposition. Observations, authority decisions and intermediate drafts remain typed internal dependencies. The native journal is the source of audit evidence. A large already-staged value is returned through native staged-answer completion; the model does not reconstruct it.

## Content project

`prepareContentProject/types.ts`: evidence, decision, scope and draft are internal typed state. Their authorization and CAS fields are needed by `confirmProjectScope`, `authorProjectDocuments`, and `finishPrivateProject`, but no external application caller needs them copied into a final report. `final.candidate.files` is the actual retained document body, already stored in the workspace. Return its stable context/repository/path/head and document paths, with the actual commit event and disposition; omit a second body copy. An explanation is not a substitute for the application value.

`open-goal-prepared-content-project-managed.ts` independently reads real source revisions, journal receipts, workspace files, privacy and commit state. It must verify the returned project handle against these observations. Old envelopes remain readable in archived verification; new qualification targets the new API and rejects invented handles. No runtime, exporter, Python decoder or vendor changes are required for this structural JSON API: they store arbitrary return values; task-specific shape interpretation lives in this verifier.

Policy remains in the hierarchical NL entry and author/review stages. The TS projection from the actual finish is exact data selection, with no authorization or quality judgment.

## Owned illustration

Its diagnostic output may retain those observations without asking the model to repeat them.

## Development audit

`reviewDevelopmentAudit/contract.ts`: assignment, observed pair and choice are internal discovery/selection state. The requested audit findings are the selected run identity, assessment (including decisive journal sequence findings) and actual keep receipt. `open-goal-development-audit-managed.ts` owns the before/after native runs, read journal and paged cursors; those independently prove scope/evidence/transition instead of comparing copied observations. Qualification rejects a foreign returned run identity and an invented assessment while preserving native wrong-scope/stale-approval probes.
